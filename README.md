# Leonida Trophy Tracker

An offline, open-source GTA VI trophy guide and tracker featuring all 55 PS5 trophies, cited guides, a platinum roadmap, prominent missable warnings, and persistent browser progress storage.

[![make.fun rank](https://make.fun/badge/gta6-trophy-guide-01/Ombray88/gta6-trophy-guide-01/rank.svg)](https://make.fun/competitions/gta6-trophy-guide-01)
[![make.fun reward](https://make.fun/badge/gta6-trophy-guide-01/Ombray88/gta6-trophy-guide-01/reward.svg)](https://make.fun/competitions/gta6-trophy-guide-01)

## How to run

Serve the `app/` directory with any static server (for example `node serve.ts`, then open http://localhost:8080). No build step required; works completely offline.
